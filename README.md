Paper Storm is a paper-plane arcade game: steer a folded paper dart through a stormy sunset sky, dodge drifting storm clouds, origami cranes and telegraphed lightning, catch stars to build a combo, ride wind rings to refill the dash, and mend a life with a paper boat. Survive 90 seconds to reach the Eye of the Storm and tame it — or lose all three planes to the weather. Keyboard (arrows/WASD, Space to dash, P to pause, M to mute) or mouse, with synthesised wind, chimes and thunder, and a best score kept in the browser.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step, no network requests: game/ is plain static files.
